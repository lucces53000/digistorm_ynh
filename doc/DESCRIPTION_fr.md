DigiStorm est une plateforme collaborative de quiz et d’activités interactives en ligne. Cette application nécessite un domaine dédié installé à la racine, ainsi que Node.js et une instance Redis isolée.

La configuration SMTP du serveur YunoHost doit être disponible pour les courriels de validation et de récupération de compte. Les fichiers téléversés sont conservés dans les données persistantes de l’application.
